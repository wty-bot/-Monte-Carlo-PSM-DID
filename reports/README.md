# reports

本目录用于存放“面向提交”的文档产物，以及能说明写作与协作过程的重要记录。

## 当前内容

- `研究报告.md`：课程作业正式研究报告，已经整合模拟设计、结果展示、理论解释、文献评价和结论
- `AI工具使用记录.md`：持续记录项目中 AI 的参与方式、阶段推进和修改历史

## 使用建议

- 提交或审阅时，优先阅读 `研究报告.md`
- 如需核查 AI 辅助过程、关键 prompt 和人工取舍，阅读 `AI工具使用记录.md`
- 报告中的图表对应 `outputs/figures/`、`outputs/checks/` 和 `outputs/tables/` 中的可复现产物

## 说明

本目录是面向提交的文字材料目录。研究报告是必交 Markdown 材料，AI 使用记录用于满足课程作业中关于人工智能工具使用留痕的要求。
