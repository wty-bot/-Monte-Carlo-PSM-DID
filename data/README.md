# data

本目录存放项目的数据层内容，按“原始模拟数据 -> 中间结果 -> 汇总结果”分层组织。

## 子目录说明

- `raw/`：任务 1 生成的模拟面板数据，按场景 `scenario_a` 到 `scenario_d` 存放，可由脚本重生成，默认不提交大文件
- `interim/`：任务 2 和扩展分析的中间产物，例如逐次模拟结果、匹配诊断、事件研究系数，可由脚本重生成，默认不提交大文件
- `processed/`：较稳定、可直接用于报告和解释的汇总结果，其中轻量汇总 CSV 会提交到 GitHub
- `external/`：论文材料索引与外部参考资料说明

## 使用约定

- 正式解释任务 2 结果时，优先使用 `processed/` 中的汇总文件
- 如果要追溯单次模拟或诊断细节，再回看 `interim/`
- `raw/` 中同时保留正式交付数据与 debug 版本，后者仅供自检和核查使用
- GitHub 提交时重点保留 `processed/` 的轻量汇总结果和 `external/论文材料.md`；大体量模拟数据按 README 中的复现命令重新生成
