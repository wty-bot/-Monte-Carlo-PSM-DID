# outputs

本目录存放项目的可视化与检查产物，是“给人看”的结果层。

## 子目录说明

- `checks/`：任务自检报告与关键检查图
- `figures/`：结果图、诊断图、事件研究图
- `tables/`：便于直接查看或引用的导出表格
- `logs/`：运行日志与进度文件

## 使用约定

- 想快速判断当前结果是否可靠，先看 `checks/`
- 想在报告中引用图表，优先看 `figures/`
- 想查看可直接引用的数值表，优先看 `tables/`
- GitHub 提交时保留报告中引用的 PNG、Markdown 自检报告和轻量 CSV 汇总表；运行日志不作为提交材料
