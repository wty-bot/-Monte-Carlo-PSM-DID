## 步骤 1：DID 回归方法审计

### 审计对象

项目中三种 DID 回归的实现：**基础 DID**（`estimate_did`）、**DID-X**（`estimate_did_x`）、**PSM-DID 的 DID 阶段**（`estimate_psm_did`）。以及四种方法的运行链路（`run_one_simulation`）。

---

### 1.1 基础 DID

#### 1.1.1 模型形式

```
Y_it = α_i + λ_t + θ × (D_i × post_t) + ε_it
```

- α_i：企业固定效应，吸收所有时间不变的个体异质性
- λ_t：年份固定效应，吸收共同时间冲击
- D_i × post_t：处理指示与处理后时期交乘项，系数 θ 即为 DID 估计量

#### 1.1.2 实现方式

**位置**：[src/estimation/methods.py:123-150](src/estimation/methods.py#L123-L150)（`_twfe_coef`），[src/estimation/methods.py:500-531](src/estimation/methods.py#L500-L531)（`estimate_did`）

不使用 statsmodels 的 OLS 虚拟变量，而是**手工 within-transformation**后做单变量回归：

```
y_dm = y - ȳ_i - ȳ_t + ȳ_..
d_dm = d - d̄_i - d̄_t + d̄_..
θ = Σ(d_dm × y_dm) / Σ(d_dm × d_dm)
```

计算逻辑：组内去均值（within-transformation）在代数上与加入全部企业和年份虚拟变量（LSDV）的点估计等价，只是算得更快。

#### 1.1.3 计量规范性检查

| 检查项 | 判定 | 说明 |
|:---|:---:|:---|
| TWFE 与 LSDV 点估计等价 | ✅ | within-transformation 在代数上等价 |
| 统一政策时点 | ✅ | t≥4 同时处理，非 staggered adoption |
| 平衡面板 | ✅ | 6 期 × 1000 企业，无缺失 |
| 单一二元处理变量 | ✅ | D_i ∈ {0,1}，无多期多剂量 |
| 场景 A 无条件平行趋势成立 | ✅ | D_i 随机、κ_i=0，TWFE 是最有效估计量 |

#### 1.1.4 审计结论

基础 DID 回归实现规范。within-transformation 与含虚拟变量的 OLS 点估计一致。数据结构为统一政策时点的平衡面板，不存在 staggered adoption 下的负权重问题。

### 1.2 DID-X

#### 1.2.1 模型形式

```
Y_it = α_i + λ_t + θ × (D_i × post_t) + γ × (X_i × s_t) + ε_it
```

其中 s_t = t-1 = {0,1,2,3,4,5}，为线性时间刻度。

#### 1.2.2 为什么用 X_i × s_t 而不是 X_i

X_i（企业初始规模）是时间不变的。若直接放入 X_i 水平项，会被企业固定效应 α_i 吸收而无法识别。交乘项 X_i × s_t 是时变的，允许 X_i 对企业绿色投资的增长斜率产生线性影响。

在场景 B/D 的 DGP 中，真实趋势项正是 κ_i × s_t = 4X_i × s_t。DID-X 显式加入 X_i × s_t 后，这部分由可观测协变量驱动的趋势异质性被吸收，消除了基础 DID 的遗漏变量偏误（场景 B 中偏误从 +8.5 降至 +0.02）。

#### 1.2.3 实现方式

**位置**：[src/estimation/methods.py:534-627](src/estimation/methods.py#L534-L627)（`estimate_did_x`）

对两个变量（D_post, X_s）同时做 within-transformation，在 demeaned 数据上手工求解 2×2 OLS：

```
[d_dm, x_s_dm]'[d_dm, x_s_dm] × [θ, γ]' = [d_dm, x_s_dm]' × y_dm
θ = (dy·xx - dx·xy) / (dd·xx - dx·xd)
```

行列式低于 1e-12 时返回 NaN，实际运行中从未触发。

#### 1.2.4 计量规范性检查

| 检查项 | 判定 | 说明 |
|:---|:---:|:---|
| X_i 以交乘项进入 | ✅ | X_i 水平项被 α_i 吸收，用 X_i×s_t 是正确处理方式 |
| s_t 线性设定 | ✅ | 与 DGP 中 κ_i×s_t 趋势规格一致 |
| demeaned 数据 OLS | ✅ | 等价于带 FE 的多元回归 |
| 逆矩阵条件数 | ✅ | det<1e-12 保护，实际从未触发 |
| 函数形式与 DGP 匹配 | ⚠️ | 场景 B/D 的 κ_i 为线性，完美匹配；场景 D 的 τ_i 含 clip() 非线性，DID-X 仅能近似 |

#### 1.2.5 审计结论

DID-X 实现规范。时间不变协变量通过交乘项进入 FE 回归是标准做法。与基础 DID 相比，DID-X 额外控制了可观测趋势异质性，是场景 B 中消除偏误的合理手段。

### 1.3 PSM-DID 的 DID 回归阶段

#### 1.3.1 两阶段流程

PSM-DID 的完整管线分两步，本审计仅覆盖第二步（DID 回归）。第一步（匹配）见 [PSM匹配审计记录](PSM匹配审计记录.md)。

```
阶段 1: Logit 倾向得分 → 共同支持裁剪 → 1:1 最近邻匹配（放回）
阶段 2: 匹配后面板上跑 TWFE DID
```

#### 1.3.2 匹配后面板构造

**位置**：[src/estimation/methods.py:152-179](src/estimation/methods.py#L152-L179)（`_build_matched_panel`）

1:1 放回匹配下，同一控制组企业可能被多个处理组企业匹配。处理方式：

- 被匹配 k 次的控制组企业复制 k 份
- 每份重命名 firm_id（如 `firm_42_rep0`）使固定效应独立
- 处理组企业各保留一份原样

等价于对被重复匹配的控制组企业赋予 k 倍频数权重。在点估计层面合理。

#### 1.3.3 DID 回归

**位置**：[src/estimation/methods.py:630-701](src/estimation/methods.py#L630-L701)（`estimate_psm_did`）

在匹配后面板上调用与基础 DID 相同的 `_twfe_coef`：

```
matched_panel["D_post"] = matched_panel["D"] × matched_panel["post"]
τ_hat = _twfe_coef(matched_panel, treatment_col="D_post")
```

#### 1.3.4 计量规范性检查

| 检查项 | 判定 | 说明 |
|:---|:---:|:---|
| DID 阶段与基础 DID 一致 | ✅ | 同一 `_twfe_coef` 函数 |
| 放回权重处理正确 | ✅ | firm_id 重命名使复制后的 FE 独立 |
| 匹配与 DID 共用裁剪样本 | ✅ | 同一批企业进入匹配和 DID |

#### 1.3.5 审计结论

PSM-DID 的 DID 阶段实现规范。放回匹配的权重通过"复制 + 重命名 firm_id"体现，在点估计上等价于频数权重。

### 1.4 运行链路

#### 1.4.1 调用顺序

**位置**：[src/estimation/methods.py:708-742](src/estimation/methods.py#L708-L742)（`run_one_simulation`）

```
每轮 MC 模拟:
  1. prepare_matching(panel)    → Logit + 共同支持 + 匹配（仅一次）
  2. estimate_did(panel)        → 全样本 TWFE
  3. estimate_did_x(panel)      → 全样本 TWFE + X×s 控制
  4. estimate_psm(panel, prep)  → 匹配后比 Y_post_mean
  5. estimate_psm_did(panel, prep) → 匹配面板 TWFE
```

#### 1.4.2 链路检查

| 检查项 | 判定 | 说明 |
|:---|:---:|:---|
| PSM 与 PSM-DID 共享匹配 | ✅ | 避免同轮两次匹配引入差异 |
| DID / DID-X 不经匹配 | ✅ | 符合方法定义，用全样本 |
| 匹配失败时 PSM/PSM-DID 返回 NA | ✅ | 不污染汇总 |
| 四种方法同一 panel 同一 sim_id | ✅ | 横向可比 |

#### 1.4.3 审计结论

运行链路设计合理。PSM 管线与 DID 管线独立，PSM/PSM-DID 共享匹配，方法间在同一数据上可比。

### 1.5 关于标准误的补充说明

当前实现仅提取回归的**点估计 θ**，不计算标准误、置信区间或做假设检验。本项目以 Monte Carlo 层面的 Bias 和 RMSE（跨 500 次模拟的 τ_hat 分布）作为评估指标，因此**当前仅提取点估计是足够的**。

若后续需报告单次回归的推断统计量，需注意：

| 事项 | 说明 |
|:---|:---|
| 聚类标准误 | DID 误差在企业内序列相关，应在 firm_id 层聚类。当前手工 within-transformation 未提供 |
| PSM-DID 两步估计的方差 | 第一步 PSM 的不确定性应传导到 DID 阶段，简单匹配后回归标准误会低估真实方差 |
| DID-X 自由度 | 额外控制 X_s 后自由度减少，应在聚类标准误中体现 |

### 2.1 Placebo DID（伪政策时点检验）

#### 2.1.1 方法逻辑

**位置**：[src/analysis/summarize.py:132-146](src/analysis/summarize.py#L132-L146)（`_preperiod_placebo_did`）

在处理前 3 期（t=1,2,3）上，将最末一期 t=3 设为"伪政策时点"，构造 `D_placebo = D_i × I(t==3)`，在仅含处理前三期的子面板上跑 TWFE：

```
Y_it = α_i + λ_t + θ_placebo × D_placebo + ε_it    (仅 t=1,2,3)
```

θ_placebo 度量政策实施前最后一期处理组与控制组之间是否已出现系统性水平差异。

#### 2.1.2 计量规范性检查

| 检查项 | 判定 | 说明 |
|:---|:---:|:---|
| 仅使用处理前数据 | ✅ | `panel["post"] == 0` 精确筛选 |
| 伪政策时点设置正确 | ✅ | 取 pre 期内最末年份，与真实 DID 口径一致 |
| 回归口径与基础 DID 相同 | ✅ | 复用 `_twfe_coef` |
| 可以检测处理前跳变 | ✅ | 对 t=3 的异常变化敏感 |

#### 2.1.3 局限

| 局限 | 说明 |
|:---|:---|
| 仅检 t=3 一个时点 | 无法捕捉 t=1→2 的慢速分化趋势 |
| 不构成完整的事件研究 | 缺少 t=1,2 各自的动态系数 |
| 单一期点检验不足以充分验证平行趋势 | 教材标准做法是展示全部处理前期的动态系数 |

#### 2.1.4 审计结论

方法实现正确，统计上可行。但其**检验充分性有限**——仅靠单点 placebo 无法充分验证平行趋势假设，需补充事件研究图。

---

### 2.2 Pretrend Coefficient（线性预趋势差异）

#### 2.2.1 方法逻辑

**位置**：[src/analysis/summarize.py:149-161](src/analysis/summarize.py#L149-L161)（`_preperiod_trend_gap`）

在处理前 3 期上构造 `pre_s = year - min(year) = {0,1,2}`，再构造交乘项 `D_pretrend = D_i × pre_s`，跑 TWFE：

```
Y_it = α_i + λ_t + γ × (D_i × pre_s) + ε_it    (仅 t=1,2,3)
```

γ 度量处理组比控制组在每期多增长的量——即差异化预趋势斜率。

#### 2.2.2 计量规范性检查

| 检查项 | 判定 | 说明 |
|:---|:---:|:---|
| s_t 从 0 起步 | ✅ | `year - min(year)` 使第一期为基线 |
| 线性趋势设定 | ✅ | pre_s = {0,1,2} 为线性刻度 |
| 与 DGP 趋势形式匹配 | ✅ | DGP 中 κ_i × s_t 为线性，pre_s 规格一致 |
| 回归口径与基础 DID 相同 | ✅ | 复用 `_twfe_coef` |

#### 2.2.3 局限

| 局限 | 说明 |
|:---|:---|
| 仅检测线性趋势差异 | 非线性（如二次、对数趋势）无法捕获 |
| 处理前只有 3 个时点 | 3 个点估计线性斜率，样本量极小，估计不稳定 |
| 与 placebo DID 互补但不同 | 前者检斜率，后者检水平跳变 |

#### 2.2.4 审计结论

方法标准、计算正确。γ 的符号和大小可直观反映处理前趋势差异的方向和幅度。但处理前仅 3 期导致估计自由度极低，且仅对线性趋势敏感。

### 2.3 处理前协变量与结果 SMD

#### 2.3.1 方法逻辑

**位置**：[src/analysis/summarize.py:108-129](src/analysis/summarize.py#L108-L129)（`_build_preperiod_features`），[src/analysis/summarize.py:91-105](src/analysis/summarize.py#L91-L105)（`_standardized_mean_difference`）

对每家企业构造三个处理前指标：

| 指标 | 构造方式 | 含义 |
|:---|:---|:---|
| `X` | 原始协变量 | 企业规模 |
| `Y_pre_mean` | mean(Y_1, Y_2, Y_3) | 处理前结果水平 |
| `pre_slope` | (Y_3 - Y_1) / 2 | 处理前结果线性斜率 |

对每个指标计算处理组与控制组的标准化均值差（SMD）：

```
SMD = (mean_T - mean_C) / sqrt((var_T + var_C) / 2)
```

#### 2.3.2 计量规范性检查

| 检查项 | 判定 | 说明 |
|:---|:---:|:---|
| SMD 公式正确 | ✅ | pooled SD 加权，与 cobalt/MatchIt 一致 |
| 仅使用处理前信息 | ✅ | 不涉及 Y_post |
| 三个指标各有侧重 | ✅ | X→协变量，Y_pre_mean→水平，pre_slope→趋势 |

#### 2.3.3 局限

| 局限 | 说明 |
|:---|:---|
| pre_mean_smd 不直接检验平行趋势 | 水平差异 ≠ 趋势差异，仅作辅助指标 |
| pre_slope_smd 更贴近平行趋势概念 | 但仍是对汇总统计量的比较，不是逐期动态系数 |
| SMD < 0.1 阈值为经验规则 | 不构成正式的假设检验 |

#### 2.3.4 审计结论

SMD 指标计算方法正确，适合用作协变量平衡性的诊断工具。`pre_slope_smd` 比 `pre_mean_smd` 更贴近平行趋势概念，但两者都不能替代逐期事件研究系数。规范用法是辅助诊断，而非正式平行趋势检验。

Before/After 对比框架设计合理，是目前项目中最接近"稳健性检验"的设计。但对比维度仅限于 5 个汇总指标，尚未扩展到事件研究的逐期系数，也缺少不同控制组构造规则的交叉验证。

### 2.6 补充检验建议（待确认后实施）

#### 2.6.1 事件研究图（Event Study）

加一个标准事件研究回归与可视化。回归形式：

```
Y_it = α_i + λ_t + Σ_{k≠3} β_k × (D_i × I(year==k)) + ε_it
```

以 t=3（处理前最后一期）为基期归一化到 0。β_1、β_2 应接近 0（平行趋势检验），β_4、β_5、β_6 为动态处理效应。在全样本和匹配样本上各跑一遍并画系数图。

#### 2.6.2 控制组构造稳健性

三种替代控制组方案：

- **方案 A——不同 caliper**：给 `_nearest_neighbor_match` 加 caliper 参数（如 0.05、0.10、0.20），限制匹配距离上限。比较各 caliper 下的平行趋势诊断稳定性。
- **方案 B——X 分箱匹配**：对 `X_i` 做 qcut 分 5 组，仅在同组内做 1:1 最近邻匹配。在场景 B/D 中特别贴合（趋势异质性完全由 X 驱动）。
- **方案 C——全样本 vs 匹配样本事件研究**：方案 2.6.1 已覆盖。

#### 2.6.3 建议实施优先级

| 优先级 | 内容 | 理由 |
|:---:|:---|:---|
| 1 | 事件研究图（全样本 + 匹配样本） | 教材标准做法，当前最大缺口 |
| 2 | X 分箱匹配 + 诊断对比 | 贴合 DGP，场景 B/D 中解释力强 |
| 3 | Caliper 变体诊断 | 更细粒度的匹配稳健性，caliper 太小可能导致匹配失败率上升 |

## 步骤 3：标准误与推断审计

### 审计对象

项目中所有与不确定性量化相关的指标、术语和实现。包括单次回归标准误（不存在）、Monte Carlo 层面的 std/rmse/分位数（存在）、以及事件研究置信带（存在）。

---

### 3.1 当前实现状态

#### 3.1.1 做了什么

项目从每次 DID 回归中**仅提取点估计 θ**，不计算标准误、t 统计量、p 值或置信区间。全部不确定性量化在 Monte Carlo 层面完成：

| 指标 | 计算方式 | 实际含义 |
|:---|:---|:---|
| `std` | 500 次模拟 τ̂ 的样本标准差 SD(τ̂) | 估计量在重复抽样下的经验标准差 |
| `rmse` | √(mean((τ̂ - τ)²)) | 估计量相对真值的均方根误差 |
| 事件研究 95% 带 | 500 次模拟 β_k 的 2.5%/97.5% 分位数 | 估计系数的 Monte Carlo 经验分布区间 |
| `bias` | mean(τ̂ - τ) | 估计量的经验偏误 |

#### 3.1.2 没做什么

| 缺失项 | 说明 |
|:---|:---|
| 企业层聚类标准误 | DID 误差在企业内序列相关，当前 within-transformation 未提供任何标准误 |
| 单次回归 95% CI | 无法对某次特定样本做统计推断 |
| t 统计量 / p 值 | 无法做单次回归显著性检验 |
| PSM-DID 两步方差 | 第一步匹配的不确定性未传导到第二步 DID |
| MCSE（Monte Carlo 标准误） | 未区分 SD(τ̂) 与 SD(τ̂)/√R |

---

### 3.2 术语澄清：std 不是 MCSE

当前汇总表中的 `std` 字段来源于 `valid.std()`（500 次 τ̂ 的样本标准差），它度量的是**估计量本身的离散程度**，而非 Monte Carlo 均值的误差。

| 公式 | 含义 | 当前是否混淆 |
|:---|:---|:---:|
| SD(τ̂) = std(τ̂_1, ..., τ̂_500) | 估计量的 Monte Carlo 经验标准差 | ✅ 表中有 |
| MCSE(τ̄) = SD(τ̂) / √500 | 模拟均值的 Monte Carlo 标准误 | ❌ 未计算 |
| 2.5%–97.5% 分位数 | 估计量的经验分布区间（非单次回归 CI） | ⚠️ 图中已画，但需注明性质 |

**审计判断**：如果项目目标是比较不同估计器在重复抽样下的偏误和方差，当前 `std` 的使用是正确的。但不应将 `std` 称为"Monte Carlo 标准误"——那是 `std/√500`。也不应将事件研究分位数带称为"回归置信区间"——它是估计量在 500 次重复抽样下的经验分布带。

---

### 3.3 为什么单次回归推断缺失不影响当前项目

当前项目的核心目标是：

> 比较 PSM、DID、DID-X、PSM-DID 在 Monte Carlo 重复抽样下的偏误、方差和 RMSE

这一目标只需要**估计量在重复抽样下的分布**，不需要在单次样本中做统计推断。因此，以下内容在当前项目中**不需要**：

- 显著性检验（"某场景下效应显著"）
- 单次回归的 p-value
- Coverage rate / rejection rate
- 单次回归 95% CI

**但如果报告中出现以上任何内容**，当前实现就是不完整的，必须先补齐聚类标准误。

---

### 3.4 若需要补充聚类标准误：技术要点

#### 3.4.1 DID 聚类标准误

DID 面板数据中，同一企业跨期误差通常相关。标准做法是在 `firm_id` 层聚类。在 within-transformation 框架下，聚类稳健方差为：

```
Var_clustered(θ̂) = (X_dm' X_dm)^{-1} [Σ_g X_dm,g' ε̂_g ε̂_g' X_dm,g] (X_dm' X_dm)^{-1}
```

其中 g 索引企业（cluster），X_dm,g 为该企业的 demeaned 设计矩阵行，ε̂_g 为该企业的 demeaned 残差向量。

当前 `_twfe_coef` 仅计算了 `(X_dm' X_dm)^{-1} X_dm' y_dm` 的点估计部分，缺少残差和中间的聚类"meat"矩阵。

#### 3.4.2 PSM-DID 的额外复杂性

PSM-DID 是两步估计：先估计倾向得分并匹配，再在匹配样本上跑 DID。若只在第二步 DID 上计算普通聚类标准误，会**忽略第一步匹配带来的不确定性**，导致标准误偏小。

正确做法是 **bootstrap 全流程**：每轮 bootstrap 中重新抽样企业 → 重新估计 Logit 倾向得分 → 重新共同支持裁剪 → 重新匹配 → 重新跑 DID 回归。否则两步方差被低估。

#### 3.4.3 事件研究聚类方差

事件研究回归有 k 个交乘项（k=5 在本项目中），聚类方差-协方差矩阵需按 `firm_id` 聚类计算，形式同上但 X_dm 和 ε̂ 维度扩展为多变量。

---

### 3.5 步骤 3 综合审计结论

| 子项 | 内容 | 判定 | 说明 |
|:---|:---|:---:|:---|
| 3.1 | 点估计 | ✅ 正确 | within-transformation 等价 LSDV |
| 3.2 | 单次回归聚类标准误 | ❌ 不存在 | 当前项目目标下可接受 |
| 3.3 | Monte Carlo std/rmse | ✅ 正确 | 度量估计量重复抽样分布 |
| 3.4 | 术语使用 | ⚠️ 需注意 | `std` ≠ MCSE，分位数带 ≠ 回归 CI |
| 3.5 | PSM-DID 两步方差 | ❌ 不存在 | 若需单次推断，须用 bootstrap 全流程 |

**整体结论**：

- **对当前项目目标（Monte Carlo 比较）而言，现有实现是充分的。** 所有不确定性通过 500 次模拟的 τ̂ 分布、分位数带和 RMSE 得到合理量化。
- **不足在于**：项目缺乏单次回归层面的推断能力，无法支持"某次样本中效应是否显著"或"coverage rate"的分析。若后续需要这类内容，必须先实现企业层聚类标准误，并对 PSM-DID 采用 bootstrap 全流程。
- **术语需校准**：`std` 应称为"估计量经验标准差 SD(τ̂)"而非"Monte Carlo 标准误"；事件研究分位数带应称为"MC 经验分布带"而非"回归置信区间"。
