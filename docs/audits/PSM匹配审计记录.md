## 步骤 3：匹配（Matching）· 审计报告

### 3.1 匹配方案

**方法**：1:1 最近邻匹配（Nearest Neighbor Matching），**放回**（with replacement）

**实现位置**：`src/estimation/methods.py:348-419`，函数 `_nearest_neighbor_match`

### 3.2 匹配算法

输入：已完成共同支持裁剪的企业层数据 + 倾向得分

算法逻辑（逐行对照代码）：

1. 分离处理组和控制组的 PS：`p_treated`、`p_control`
2. 对控制组 PS 排序：`p_control_sorted = np.argsort(p_control)`
3. 对每个处理组企业 `p_t`：
   - 用**二分查找** (`np.searchsorted`) 找到控制组 PS 中最接近的位置
   - 比较左右两侧的距离，选更近的一侧
   - 记录匹配的控制组索引和距离
4. 时间复杂度：O(T × log C)，好于朴素的 O(T × C)

### 3.3 放回（With Replacement）机制

因为没限制一个控制组企业只能用一次，所以：
- 同一个控制组企业可能被多个处理组企业匹配
- 控制组去重后的数量 ≤ 匹配对数
- 被多次匹配的控制组，在后续估计中按匹配次数加权

### 3.4 PSM 如何使用匹配结果

代码 `estimate_psm`（第 426-497 行）：

```
对每个匹配对：
  Δ = treated.Y_post_mean - matched_control.Y_post_mean
τ_hat_PSM = mean(所有匹配对的 Δ)
```

**关键**：PSM 比较的是**处理后的结果水平**，不是前后变化。它依赖匹配来让处理组和控制在 X 上可比，但不做差分。

### 3.5 PSM-DID 如何使用匹配结果

代码 `estimate_psm_did`（第 630-701 行）+ `_build_matched_panel`（第 152-179 行）：

```
1. 拿到匹配对 → treated_firm_ids, control_firm_ids
2. 从原始 6 期面板中取出这些企业的完整面板数据
3. 控制组企业若被重复匹配，复制对应次数（重命名 firm_id 以保持固定效应独立性）
4. 在匹配后的面板上跑 TWFE DID:
   Y_it = α_i + λ_t + θ × (D_i × post_t) + ε_it
   τ_hat_PSMDID = θ
```

**关键**：PSM-DID 先用匹配解决 X 上的可比性，再回到面板做 DID 回归差分掉企业固定效应，**同时处理可观测混淆和时间不变不可观测混淆**。

### 3.6 匹配质量指标

| 场景 | 方法 | 平均匹配距离 | 控制组去重数/匹配对数 |
|:---|:---|:---:|:---:|
| A | PSM / PSM-DID | 5.02e-05 | （几乎 1:1，因放回但 PS 接近） |
| B | PSM / PSM-DID | 1.11e-03 | 控制组被重复匹配 |
| C | PSM / PSM-DID | 1.85e-04 | 控制组重复匹配较少 |
| D | PSM / PSM-DID | 1.12e-03 | 同 B |

### 3.7 步骤 3 审计结论

匹配实现正确：1:1 最近邻 + 放回，二分查找优化 O(T log C)，匹配距离整体合理。PSM 和 PSM-DID 共用同一套匹配结果，后续估计口径不同——PSM 比处理后水平差，PSM-DID 比前后变化差。

## 步骤 4：平衡性检验（Balance Diagnostics）· 审计报告

### 4.1 实现位置

`src/analysis/summarize.py:95-268`，函数 `compute_identification_diagnostics`

### 4.2 检验指标

共 5 项指标，分两组：

**第一组：协变量与结果平衡性（SMD）**

| 指标 | 公式 | 阈值 | 检验目的 |
|:---|:---|:---|:---|
| SMD(X) | `(X̄_T - X̄_C) / √[(Var_T+Var_C)/2]` | < 0.1 | 匹配变量本身是否平衡 |
| SMD(Y_pre_mean) | 同上，对处理前均值 | < 0.1 | 处理前结果水平是否平衡 |
| SMD(pre_slope) | 同上，对处理前斜率 | < 0.1 | 处理前趋势是否平行（DID 关键假设） |

**第二组：直接预趋势检验（处理前 placebo + 系数）**

| 指标 | 方法 | 检验目的 |
|:---|:---|:---|
| Placebo DID | 在处理前 3 期假装 t=3 是政策发生点，跑 TWFE DID | 若不等于 0，说明处理前就存在系统性差异 |
| Pretrend coef | 在处理前 3 期估计 `D_i × s_t` 的系数 | 若不等于 0，说明两组预趋势斜率不同 |

### 4.3 放回匹配下的加权

匹配后 SMD 使用 `_build_matched_panel()` 构造的样本计算——被重复匹配的控制组企业按匹配次数复制。这样算出的 SMD 对应真实进入估计的加权样本，而不是去重后的控制组集合。

### 4.5 场景解读

- **A**：全部通过——随机分配下本就没差异，匹配聊胜于无

平衡性检验实现全面且正确：3 层 SMD + 2 项直接预趋势检验，放回匹配下按匹配次数加权。结果与 DGP 设定高度一致——场景 B/D 匹配后全部平衡，场景 C 的 X 平衡但预趋势不平衡（恰是 DGP 预期的不可观测混淆信号）。

## 步骤 5：估计处理效应（PSM 管线内）· 审计报告

PSM 和 PSM-DID **共用同一套匹配结果**，但计算 τ_hat 的方式完全不同。

### 5.1 PSM 的估计公式

实现位置：`src/estimation/methods.py:462-479`

```
对每个匹配对 j = 1, ..., n：
  Δ_j = treated_j.Y_post_mean − matched_control_j.Y_post_mean

τ_hat_PSM = (1/n) × Σ_j Δ_j
```

- 数据形态：企业层静态表（每个企业一行）
- 比的什么：**处理后的结果水平**，不是前后变化
- 没有差分，没有控制企业固定效应，没有控制时间趋势
- 前提假设：匹配后两组在 X 上可比，水平差即为因果效应

### 5.2 PSM-DID 的估计公式

实现位置：`src/estimation/methods.py:664-683` + `_build_matched_panel`（152-179 行）

**第一步**：匹配结果还原为面板

```
取出 treated 和 matched control 对应企业的 6 期完整面板
控制组企业被重复匹配 → 复制对应次数
重命名 firm_id（"firm_42_rep0", "firm_42_rep1"）→ 固定效应独立
```

**第二步**：在匹配后面板上跑 TWFE DID

```
Y_it = α_i + λ_t + θ × (D_i × post_t) + ε_it
用 within-transformation（_twfe_coef）求解 θ
τ_hat_PSMDID = θ
```

- 数据形态：6 期长面板
- 比的什么：**前后变化差**
- 控制了企业固定效应（差分掉时间不变的个体特征）
- 控制了年份固定效应（吸收共同时间冲击）
- 前提假设：匹配后条件平行趋势成立

### 5.3 PSM vs PSM-DID 关键区别

| | PSM | PSM-DID |
|:---|:---|:---|
| 数据形态 | 企业层静态表 | 匹配后 6 期面板 |
| 估计对象 | 处理后水平差 | 前后变化差（DID） |
| 控制 α_i？ | ❌ 未控制 | ✅ TWFE 差分掉 |
| 控制 λ_t？ | ❌ 未控制 | ✅ 年份 FE 吸收 |
| 依赖假设 | 匹配后水平可比 | 匹配后条件平行趋势 |
| 估计目标 | ATT | ATT |

### 5.4 场景 C 中 PSM 比 PSM-DID 更差的原因

场景 C：Bias_PSM = +14.8，Bias_PSMDID = +8.6。

根因：α_i = 100 + 10X_i + **5U_i** + η_i。U_i 既在个体固定效应里，又在趋势 κ_i = 4U_i 里。PSM 两个都控制不了→双重吃亏。PSM-DID 通过 TWFE 差分掉了 U_i 的水平部分，所以偏误从 14.8 降到 8.6——但仍然偏，因为 U_i × s_t 的趋势差异差分不掉。

### 5.5 步骤 5 审计结论

PSM 和 PSM-DID 的估计公式实现正确。两者共用匹配口径、分岔在估计口径：PSM 在企业层比水平，PSM-DID 回到面板跑 TWFE。这种设计使得二者差异可被干净地归因于"是否差分掉固定效应"。

## 步骤 6：敏感性分析（Sensitivity Analysis）· 审计报告

### 6.2 已补充（本次审计中实现）

**Rosenbaum 边界检验**

实现位置：`src/analysis/sensitivity.py:26-128`，运行脚本 `scripts/run_sensitivity.py`

方法说明：标准 Rosenbaum 检验 H0"处理效应为零是否可由隐藏偏误推翻"，对本项目不适用（τ=50 太大，Γ 推不翻）。因此改为**中心化 Rosenbaum**——检验"偏离 τ=50 的残余偏误是否可由隐藏偏误解释"：

- PSM：对 `(treated.Y_post_mean − 50) − control.Y_post_mean` 做 Wilcoxon signed-rank
- PSM-DID：对 `(treated.DeltaY − 50) − control.DeltaY` 做 Wilcoxon signed-rank
- 场景 D 用匹配后样本的真实 ATT 替代 50

Γ* 的含义：刚好使 p_upper ≥ 0.05 的最小 Γ。Γ* 越小 → 残余偏误越脆弱 → 轻微隐藏偏误即可解释 → 方法在该场景表现好（偏误近零）。Γ* 越大 → 残余偏误越顽固 → 即使有隐藏偏误也难以完全解释 → 方法在该场景存在系统性偏误。

结果：

| 场景 | PSM Γ* 均值 | PSM Γ* 中位 | PSM %≤1.5 | PSM-DID Γ* 均值 | PSM-DID Γ* 中位 | PSM-DID %≤1.5 |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| A | 1.01 | 1.00 | 100.0% | 1.01 | 1.00 | 100.0% |
| B | 1.02 | 1.00 | 99.8% | 1.01 | 1.00 | 100.0% |
| C | **2.08** | **2.10** | **0.8%** | **2.18** | **2.20** | **0.4%** |
