# docs

本目录存放项目的“过程层文档”，重点保留项目是如何被规划、推进、审计和解释的。

## 子目录说明

- [plans](</d:/ClaudeProjects/因果推断与机器学习课程作业/docs/plans>)：任务规划文档与通用规划文档
- [audits](</d:/ClaudeProjects/因果推断与机器学习课程作业/docs/audits>)：PSM 匹配、DID 回归等专项审计记录
- [process](</d:/ClaudeProjects/因果推断与机器学习课程作业/docs/process>)：研究过程、阶段总结、接近总说明书的综合文档

## 为什么这些文档保留在仓库中

这些文档不是“临时草稿垃圾”，而是课程作业过程留痕的一部分：

- 规划文档反映当时的设计思路
- 审计记录反映关键方法如何被复核
- 研究过程文档反映项目如何从规划走到结果

即使后续执行与早期规划存在差异，也应保留，以便老师理解 AI 参与下的完整推进过程。

另外，部分历史文档中仍会出现重组前的旧文件位置写法。这些表述保留为当时阶段的真实记录，不单独回写覆盖。
